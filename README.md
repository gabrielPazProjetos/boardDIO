--- Criando seu Board de Tarefas com Java
- Descrição
Este projeto é uma aplicação de linha de comando desenvolvida em Java 17, que simula um board de tarefas com colunas e cartões.
Ele foi criado como parte do desafio da Digital Innovation One (DIO), com foco em boas práticas de arquitetura, persistência com JDBC puro, e implementação de regras de negócio.

--- A aplicação permite:
Criar quadros e colunas
Adicionar, mover, bloquear, desbloquear e cancelar cartões
Visualizar o estado atual do board e seus elementos
Gerenciar tudo via menus interativos no terminal

--- Tecnologias utilizadas
Java 17
JDBC (Java Database Connectivity)
MySQL
Liquibase
Gradle
Lombok
JUnit 5 (opcional para testes)
